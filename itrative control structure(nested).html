1. Write a program to print the pattern on the screen.

Question 1: Pattern Printing

C Program

#include <stdio.h>

int main(void)
{
    int i, j;

    for (i = 1; i <= 5; i++)
    {
        printf("1");
    }

    printf("\n");

    for (j = 1; j <= 10; j++)
    {
        printf("1");
    }

    printf("\n");

    return 0;
}

Sample Output

11111
1111111111
