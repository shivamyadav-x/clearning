1. What is C Language?

C is a general-purpose programming language used to develop software and applications.

2. History of C

C language was developed by Dennis Ritchie at Bell Laboratories in 1972.

3. Key Features of C

C is simple, fast, portable and structured. It supports functions, pointers and operators.

4. Why Learn C?

C helps us understand programming basics, logic building, variables, loops and functions.

5. Applications of C

C is used to develop operating systems, embedded systems, compilers and system software.
